          Keyboard help

          • Tab indents inside the editor. To leave it, press Esc then Tab (or toggle “Tab moves focus”).
          • F6 moves between the toolbar, the editor, the preview and the console.
          • File buttons and the size handles use the arrow keys. Show one, two or three files with the buttons next to the files; drag a file (or a pane's title) to move it, drag the line between panes to resize.
          • While suggestions are shown, Tab or Enter takes the highlighted one. In HTML, type a tag name (div, ul.menu, section#top) at the start of a line.
          • A face in the toolbar jumps to that person's cursor. The status bar switches keymap and theme in one click.
